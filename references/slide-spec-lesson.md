# 新授課互動簡報規格手冊 (slide-spec-lesson)

> 這是專門為**各章節新課（新授課）**設計的互動投影片規格。
> 新課與複習課的核心差別在於：**不是直接給結論背口訣，而是引導學生透過情境思考、動手操作滑桿、在動態變化中自主發現規律，完成形式化抽象與階梯演練。**

---

## 一、 章節檔案骨架 (`chN.js`)

每個 `chN.js` 代表一章（或一個大單元新課），包在 IIFE 內並 push 進 `window.DECK`。

```js
/* ============ 第 N 章　章名 (新授課) ============
   教材來源：人教B版 / 康軒 / 翰林 必修第X冊
   章節目標：情境引入 → 動態探索 → 概念建構 → 易混辨析 → 典例拆解 → 隨堂檢測
   ============================================================ */
window.DECK = window.DECK || [];
(function () {
  const C = '#2563eb'; // 本章主題色 (藍/紫/綠/琥珀/玫紅/青)
  const RED = '#e11d48', GRN = '#059669', BLU = '#2563eb', VIO = '#7c3aed', AMB = '#d97706';

  function svg(vb, inner) {
    return `<div style="width:100%;text-align:center"><svg viewBox="${vb}" style="max-width:100%">${inner}</svg></div>`;
  }

  window.DECK.push({
    ch: N,
    title: '章名',
    color: C,
    sections: ['N.1 節名一', 'N.2 節名二'],
    slides: [
      /* ---------- N.1 節名一 ---------- */
      // 標準新課 6 部曲投影片
    ]
  });
})();
```

## 二、 新課標準 6 大頁型 (`type`)

每一小節（如 10.1 導數的概念）建議包含以下 6 張投影片，構成完整的課堂探究閉環：

| 頁型代碼 (`type`) | 頁面名稱 | 教學角色與定位 | 必備元素與特徵 |
| :--- | :--- | :--- | :--- |
| `hook` | **情境引入** | 提出實際物理/生活/幾何問題，引發認知衝突與思考需求 | 思考問句、幾何模型圖或生活情境圖、`caption` 思考問題 |
| `explore` | **動態探索** | 提供動態操作儀，讓學生手動逼近、觀察規律並提出猜想 | `inquiry`（探究任務導引條）、`<input type="range">` 滑桿、動態幾何/函數變化 |
| `concept` | **新知概念** | 從剛才的探索中提煉數學本質，給出符號記號與嚴謹形式化定義 | `formula` 核心公式、`SV.fbox` 結構卡片、3~4 條要點 |
| `pitfall` | **概念辨析** | 透過反例、邊界條件、易混淆概念深化理解 | 反例圖形、尖點/不連續點分析、或 `SV.quiz` 概念辨析題 |
| `example` | **典例剖析** | 示範解題通法，提供審題路徑與分步思維階梯 | `thinking`（審題思考）、`hints`（啟發提示）、`steps`（解答步驟）、`variant`（變式） |
| `practice` | **隨堂即練** | 課堂形成性檢測，學生當堂反饋 | `SV.quiz` 互動選項卡片，點擊後即時反饋對錯與解析 |

## 三、 投影片物件欄位全定義

```js
{
  sec: '10.1',                  // [必填] 節次代碼
  secName: '導數的概念',         // [必填] 節次名稱
  type: 'explore',              // [必填] 新課頁型：hook | explore | concept | pitfall | example | practice | summary
  title: '割線的極限位置即為切線', // [必填] 核心主題句或探究問句（大標題）

  inquiry: '請拖動下方滑桿讓點 Q 沿著曲線向點 P 逼近，觀察割線斜率的數值變化！',
                                // [選填·探索頁必備] 頂部探究導引條

  formula: {                    // [選填] 核心公式卡，置中渲染為 $$...$$
    label: '導數定義式',
    tex: 'f\'(x_0) = \\lim_{\\Delta x \\to 0} \\frac{f(x_0+\\Delta x)-f(x_0)}{\\Delta x}'
  },

  points: [                     // [選填] 2~4 條概念要點，講機制與理解，每條 ≤ 45 字
    '當割點 \\(Q\\) 無限逼近固定點 \\(P\\) 時，割線轉動並趨於穩定極限位置。',
    '此時割線的極限位置直線，定義為曲線在 \\(P\\) 點的<b>切線</b>。'
  ],

  visual: (h) => {              // [選填] 右側動態視覺繪製函式，h 為容器元素
    // 使用 SV.plane, SV.func, SV.secant, SV.tangent 等進行動態繪圖
  },

  caption: '圖中紅色虛線為動態割線，綠色直線為切線。', // [選填] 右欄底部說明文字

  example: {                    // [典例頁選填] 階梯式例題結構
    q: '求曲線 \\(y=x^2\\) 在點 \\(P(1,1)\\) 處的切線斜率。',
    thinking: '根據定義，先計算差商增量比值，再求當 \\(\\Delta x \\to 0\\) 時的極限。',
    hints: [
      '計算函數增量：\\(\\Delta y = (1+\\Delta x)^2 - 1 = 2\\Delta x + (\\Delta x)^2\\)',
      '約分寫出差商比值：\\(\\frac{\\Delta y}{\\Delta x} = 2 + \\Delta x\\)'
    ],
    steps: [
      '差商為：\\(\\frac{f(1+\\Delta x)-f(1)}{\\Delta x} = 2+\\Delta x\\)',
      '取極限：\\(\\lim_{\\Delta x \\to 0}(2+\\Delta x) = 2\\)'
    ],
    ans: '切線斜率 \\(k = 2\\)',
    variant: {
      q: '【即堂變式】求同一曲線在點 \\((2,4)\\) 處的切線斜率。',
      ans: '\\(k = 4\\)'
    }
  },

  quiz: {                       // [隨堂評量/辨析頁選填] 課堂即問即答
    q: '函數在某一點連續，是否代表它在該點一定可導？',
    options: [
      'A. 一定可導',
      'B. 不一定可導（尖點即為典型反例）',
      'C. 一定不可導'
    ],
    ans: 1,                     // 正確選項索引（0 起算）
    explain: '連續只保證圖形不斷開，若存在尖銳拐角（如 y=|x| 在 x=0），左右割線極限不同，因而不可導。'
  }
}
```

## 四、 嚴格編寫守則

1. **禁用 `document.getElementById`**：
   * 所有視覺欄動態元素查找一律使用 `h.querySelector('#id')`。所有投影片共用同一個 DOM 樹，直接使用全域 ID 會產生嚴重的跨頁污染。
2. **滑桿輸入規範**：
   * 控制列容器 class 必須為 `ictrl`，即時數值顯示元素 class 為 `ival`。
   * 滑桿必須給定具體的 `min`、`max`、`step`、`value`。
   * 繪圖函式末尾務必手動執行一次 `draw()`，確保投影片初次渲染時圖形非空。
3. **避免除零與 NaN 邊界**：
   * 在極限逼近（如 $\Delta x \to 0$）時，滑桿最小值避免設為精確的 `0`，應設為小量（如 `min="0.02"`），或在代碼中加入保護：`const dx = Math.abs(val) < 1e-4 ? 1e-4 : val;`。
4. **SVG viewBox 寬高比安全規範**：
   * 視覺欄 SVG 的 `viewBox` 寬高比必須 $\ge 1.25$（建議 $1.35 \sim 1.55$），寬度推薦 $400 \sim 450$、高度 $\le 300$。
   * 若圖形過高，引擎的投影自動縮放機制會將整個畫面過度等比縮小，導致學生看不清文字。
5. **MathJax 3 轉義規約**：
   * 行內公式一律使用 `\\( ... \\)`（JS 字串內請雙反斜線）。
   * `formula.tex` 內部已由引擎自動包裝 `$$`，千萬不要再寫 `$$`。
